# Idea Vault

Personal ideas, projects and lists. Next.js on Vercel, data in the `ideas` schema of the HMK Supabase project.

Environment variables: NEXT_PUBLIC_SUPABASE_URL, SUPABASE_ANON_KEY, IDEAS_DB_EMAIL, IDEAS_DB_PASSWORD, APP_PASSWORD, SESSION_SECRET.
Database setup: run supabase/migrations/0001_ideas.sql once (replace OWNER_EMAIL_HERE first).
Deployed on Vercel in the HMK team.
